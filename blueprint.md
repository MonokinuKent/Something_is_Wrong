# SOMETHING IS WRONG BLUEPRINT

## Game Concept
**Something is Wrong** is a **simulation game** where users can experience what it is like to _lose friends due to a certain issue_. Users have to choose **two options:** _Initiate first or wait for them to initiate_. However, it is not that easy to decide one of those options. So, the users have to **find out** the _main issue_ between the _main character and their friends_ and users have to **identify** who causes the problem so the users can finally decide the moves. Not only identifying, users also can have **ability** to _support_ the game mechanics. This game won't be a **repetitive** game that makes users get bored easily and know the next move accurately. This game allows users to **customize the character** and **the personality** that affects the _gameplay_. Users must **deal** with a lot of people with _different_ characters and personalities.

## V.1.0.0 FEATURES
- Game 2D pixel.
- 5 characters can be chosen.
- 5 Big Personality Traits.
